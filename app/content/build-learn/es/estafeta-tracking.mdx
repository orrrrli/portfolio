## Estafeta no tiene API de rastreo

Si has hecho un e-commerce en México, seguro te tocó: el cliente envía con Estafeta y sus compradores quieren saber dónde va su paquete. Buscas una API de rastreo y no hay.

Lo que hay es el formulario de su sitio. Metes el número y te regresa una tabla en HTML. No hay JSON, ni webhooks, ni tokens.

Existe Envia, que sí ofrece rastreo por API. Pero contratar un agregador solo para consultar el estatus es demasiado, cuando ese dato ya es público para cualquiera que tenga el número de guía.

La solución típica es un scraper que carga la página completa, muchas veces en un navegador headless (un Chrome sin ventana) como Puppeteer. He visto eso, `cheerio` y hasta curl con `grep`, y yo también he escrito alguno. Son pesados y lentos, y se rompen cuando Estafeta cambia su HTML.

## Qué encontré

Buscar un número en el sitio toma dos requests, y los dos se ven en la pestaña Network de DevTools. Un GET a la página de búsqueda deja las cookies de sesión. Luego la página pide el historial de eventos con un POST a un endpoint interno, enviado como request XHR (`X-Requested-With`). Ese endpoint regresa solo un fragmento de HTML: el timeline de estatus, nada más.

Así que me salté el navegador y escribí una API chica que repite esos dos requests:
- Recibe el número de rastreo en la ruta y lo valida
- Manda el GET para las cookies y luego el POST con los headers que el endpoint espera (`X-Requested-With`, `Referer`)
- Parsea el fragmento con AngleSharp y selectores CSS, y regresa siempre el mismo JSON: el estatus actual y el historial de eventos
- Guarda cada resultado en cache 10 minutos

Sigue siendo un scraper, porque lee HTML. Pero es uno ligero: sin navegador y sin página completa, solo el fragmento que usa el timeline. No tiene base de datos, cola ni auth.

## El endpoint

```
GET https://lab.orlando.codes/api/v1/tracking/:number
```

Pasa un número de rastreo de Estafeta en `:number` y te regresa JSON.

Con un número válido recibes el estatus actual y el historial de eventos, cada uno con su fecha, ubicación y estatus. Con uno inválido o que no existe recibes un mensaje de que no se encontró nada. Eso también sirve: te dice que la conexión funciona y que el problema es el número, no tu integración.

Pruébalo aquí. Cambia el valor en **Path** por un número de rastreo real:

<APIPlayground
  url="https://lab.orlando.codes/api/v1/tracking/:number"

## Para qué sirve

Con el estatus en JSON puedes:

- Mandar avisos de envío por WhatsApp o SMS sin estar consultando la página
- Guardar el historial en tu base de datos por si hay una disputa
- Hacer una página de rastreo con tu marca en vez de mandar al cliente al sitio de Estafeta
- Avisar a operaciones en cuanto un paquete se queda detenido

## Limitaciones

No es una integración oficial. Estafeta no aprobó este uso del endpoint y lo puede cambiar cuando quiera.

Además es scraping, así que depende del HTML del fragmento. El parser busca clases CSS específicas (`.row.eventInfo`, `.col-sm-7`). Si Estafeta las renombra, la API responde "no encontrado" aunque el número sea válido.

Corre en mi servidor de pruebas. Es una prueba de concepto, sin SLA. Si lo vas a usar para algo en serio, monitorea el endpoint y ten un plan B.

Si hay interés, lo siguiente sería una versión bien hospedada con rate limiting, monitoreo del parser y changelog.

## Qué aprendí

Lo más difícil fue armar el request correcto, no el parser. El endpoint interno solo responde si llevas las cookies de sesión de la página de búsqueda y los headers `X-Requested-With` y `Referer`. Para dar con eso tuve que leer las trazas de red con calma.

Después vino el parseo. El historial viene agrupado por día: cada grupo tiene una fecha y varios eventos adentro. Cada evento se convierte en una entrada con fecha y hora, ubicación y estatus, y las filas sin estatus se descartan.

El scraper y el parser caben en un archivo de unas 100 líneas. Alrededor hay una API chica en ASP.NET Core con MediatR, FluentValidation y cache en memoria. Corre en un VPS chico y no depende de nada más que del sitio de Estafeta.
